# 同舟婚恋 · 会员卡片生成器

[打开在线工具](https://lyong1982.github.io/tongzhou-member-card/)

填写资料，选择照片并调整构图，点击“生成并下载 PNG”。无需解压或安装。

## 技术与使用

原生 HTML / CSS / JavaScript + Canvas，使用 GitHub Pages 静态 HTTPS 托管，无服务器、数据库、构建依赖或外部脚本。

男生蓝色“他的资料”，女生粉色“她的资料”；输出 1440×1080 PNG。品牌、标语、小船来自内置完整底图。姓名必填但不会显示在图片或文件名里，出生日期只选择年份。保持直接生成下载，无成品预览。

照片和完整资料只在浏览器本地处理，不上传到 GitHub；关闭页面后清除。网页、代码及底图公开，GitHub 会记录常规站点访问信息。

编号 TZ0001–TZ9999，保存在当前网址及浏览器的 localStorage；可设置起始号。同一页面重复生成沿用原号，改姓名或重置后分配新号。多台电脑不共享计数。**从离线版迁移时，将起始号设置为已用最大编号加一。**

PNG/JPG/WebP/GIF 首帧等可用，其他图片格式依浏览器解码能力；不能解码时请转换为 PNG/JPG。竖图可向下拖动以保留头顶，不做自动人脸识别或抠图。

完整操作和限制见 [使用说明](README.txt)。建议 PC Chrome 或 Edge。

## 部署

GitHub Pages 发布来源：main 分支根目录，`.nojekyll` 禁用 Jekyll 处理。运行文件相对引用，可部署于项目子路径；也可将文件下载后直接打开 index.html。

发布文件仅包含本工具及品牌资源，不包含任何会员后台、真实会员资料、环境配置、私钥或账号凭据。底图与 Logo 为同舟婚恋品牌素材，公开可访问不代表授予第三方商标或素材使用许可。
