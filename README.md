# 同舟婚恋 · 会员卡片生成器 V1.6.2

[打开在线工具](https://lyong1982.github.io/tongzhou-member-card/)

填写资料、上传照片、调整构图，点击“生成卡片”进入最终预览。选择“保留原照”或“卡通遮挡”，确认后点击“保存下载”。

男版晴蓝、女版柔粉采用Figma左图右文设计：照片3:4，整张PNG为1440×1080（4:3）。选择遮挡即显示对应性别的透明PNG头像，没有圆形底板，可点击定位、拖动和缩放。遮挡会实际合成进下载图片。

卡片显示八项基础资料、家庭情况、红娘评价、择偶要求及编号，不显示姓名、年龄。正文按实际字体测量，超出空间明确提示，不能静默截断。系统中文字体与Figma的Noto Sans SC可能有细微差异。

初次打开及重置时，民族默认为汉族且可编辑，婚姻默认为未婚，其余资料为空。出生年份手填四位数字，婚姻提供六个选项。资产、红娘评价与择偶要求提供填写提示，提示不进入生成的卡片。择偶要求应由会员提出，整理后的内容须经会员确认。

下载文件名为“编号_姓名_出生年份_性别.png”，例如`TZ-00100_张三_1982_男.png`；姓名仅进入文件名，卡片画面不显示姓名。文件系统非法字符替换为下划线，重复文件名由浏览器处理。

## 编号与隐私

默认显示建议编号，首次预览不占号，首次保存才分配TZ-00001–TZ-09999；同页同一会员重复保存沿用原号。可点击修改编号，允许当前会员原号或不低于下一序号的新号；指定高号会跳过中间号段。保留旧浏览器计数。改姓名、重置、刷新后不恢复原会员归属。

计数仅保存在同一浏览器存储范围内，不保证跨设备或不同浏览器全局唯一。照片、姓名、资料和遮挡参数仅在页面内存中处理，不上传或持久保存；刷新会清除。

卡通遮挡自动放在照片上部中央，需手动调整并检查覆盖范围，不做人脸识别。照片背景和资料不因遮脸而匿名化。

## 技术与部署

原生HTML/CSS/JavaScript + Canvas；GitHub Pages main分支根目录静态托管，无服务端、数据库、构建依赖、外部字体或脚本。资源相对引用，也支持本地file://打开。

JPG/PNG/WebP/GIF首帧等可用，其他格式以浏览器解码能力为准。建议PC Chrome或Edge。详细说明见[使用说明](README.txt)。

发布仅包含工具运行文件、品牌背景和用户指定卡通素材，不含会员后台、真实会员资料、测试照片、环境配置或凭据。品牌素材公开可访问不代表授权第三方使用。

页头“本机已打开 N 次”仅统计当前浏览器、当前站点。新打开或刷新页面加1，编辑、预览、下载、重置不增加。清除站点数据后重新计数；其他电脑或浏览器各自统计。次数不代表使用人数，不上传任何访问统计数据；统计不可用不影响卡片功能。
