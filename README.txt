一、在线使用与打开
网页版：https://lyong1982.github.io/tongzhou-member-card/
直接打开网址，填写资料、选择照片、调整构图，点击生成并下载 PNG。
网页采用 HTML/CSS/JavaScript + Canvas，由 GitHub Pages 静态托管，无需安装。
页面及代码/底图公开；照片和表单资料只在本机处理，不上传到 GitHub。
访问网站需要网络，GitHub 会记录常规页面访问信息；工具不发送会员资料。
首次从离线版迁移到网址时，请把起始号设为已用最大编号加一。
不同浏览器、电脑或网址不共享计数，不保证跨设备编号唯一。

仍可使用本地文件：
1. 将 ZIP 完整解压，不要直接在压缩包内运行。
2. PC 上用 Chrome 或 Edge 打开 index.html，运行无需联网、服务器或安装依赖。
3. index.html、styles.css、app.js 和 assets 文件夹请保持原有位置。
4. 更新版本时，在原文件夹替换运行文件，并继续使用同一浏览器与用户配置。
   换浏览器、换电脑、换路径或清除数据后，计数可能不延续；迁移前记下已使用的最大编号。

二、填写与生成
1. 填写姓名（必填，1–40 个字符）。姓名仅用于当前页面录入，不显示在卡片和文件名中。
   不会保存姓名与编号的对应关系；重新打开后再次录入同一人会分配新编号。
2. 选择“他的资料 · 蓝色”或“她的资料 · 粉色”，分别使用内置蓝色、粉色完整底图。
   标题与资料面板同步配色，成品不显示性别字段。
3. 出生年份下拉选择，例如 1982 年，无需月份。
   年龄用当前年份减出生年份，显示“约44岁”等估算值，并非精确周岁。
4. 填写基本资料和介绍。初始介绍仅是示例，请替换为已授权的真实资料。
5. 点击“上传照片”选择会员图片，上传后按钮变为“更换照片”。
   取消文件选择不丢失已读取的照片。照片仅在本机读取，不通过网络上传。
6. 在照片调整区拖动、缩放，或用方向键微调（Shift + 方向键快速移动）。
   调整区与成品照片框同为 568×404 比例，请将脸部及肩部放入框中。
   竖版照片可能需要向下拖动保留头顶，不会自动识别人脸或抠图。
   “居中”只重置位置，“重置构图”恢复初始缩放和居中。
7. 品牌 Logo、标语、波浪、小船均随原底图固定内置，不另外叠加。
   表单不提供 Logo 上传或恢复按钮。粉色图自带底部题字，蓝色图保留原有风景。
8. 点击“生成并下载 PNG”，直接下载最新资料，没有成品预览步骤。
   保存位置由浏览器设置决定，连续下载可能需允许浏览器的下载权限。
9. 制作下一位会员时点击“重置”。姓名、照片和当前编号清空，示例资料恢复，累计编号保留。

三、编号规则
- 编号是 TZ 加四位数字，范围 TZ0001–TZ9999，显示在卡片资料标题右侧和文件名中。
- 默认从 TZ0001 开始。在“设置起始序号”中输入 1–9999 并保存，可设置下一份新资料起始号。
- 第一次尚未发号时可以调整起始号；已经发号后只允许将待分配号调高，不允许回退复用。
- 资料、照片、当前主题底图、文字排版和 PNG 转换都通过后才分配编号；先保存计数，再发起下载。
- 同一页面同一份资料重新生成沿用原号。修改资料/照片不换号；修改姓名后下一次生成分配新号。
- 重置后制作下一位分配新号；关闭/刷新后不恢复上次资料和编号，下一次生成会用新号。
- 下载被取消、浏览器阻止下载或保存中断可能留下空号；已分配号码不回收。
- TZ9999 用完后停止新编号生成，当前已编号卡片仍可重复下载，不回绕到 TZ0001。
- 单机计数仅保存在当前浏览器的本地存储作用域，不保证跨浏览器、电脑或路径唯一。
  不要清除浏览器数据。迁移后须把起始号设为既有最大编号加一。
- 多窗口使用排他协调避免重复发号。优先 Web Locks，缺失时采用 IndexedDB 排他事务。
  两种能力都不可用时停止发号，请使用允许本地存储的新版 Chrome/Edge。
- 记录无法读取、损坏或无法保存时会停止分配，不能静默从 0001 重新开始。

四、图片与文字
- 输出固定 1440 × 1080 像素、4:3 横版 PNG。
- 原底图为 1448×1086，生成时等比缩放，不裁切、不拉伸。
- 中部左侧资料与家庭、右侧照片；下方双栏为红娘评价与择偶要求。
  顶部品牌和底部装饰保留完整，不随填写内容改变布局。
- PNG、JPG/JPEG、WebP、GIF 首帧可用，BMP 以浏览器实际解码能力为准。
- 上传入口接受 HEIC/HEIF、AVIF、TIFF 等扩展格式，浏览器能解码才能使用。
  未附带 HEIC/TIFF 解码器，不承诺“所有格式”；无法读取时请先转成 PNG/JPG。
  SVG/SVGZ 不接受。
- 单张最大 20MB、5000 万像素，单边不超过 20000px。建议长边至少 1600px，优选 2000px 以上。
- 等比裁切，不拉伸；有效裁切像素不足时提示，但允许继续。不含抠图、人脸识别或美颜。
- 手机 JPEG 方向由浏览器读取后冻结，GIF 动画使用文件首帧。
- 家庭情况、红娘评价、择偶要求各最多 100 个 Unicode 码点。
  复合 Emoji 可能包含多个码点，超限不会静默截断。
- 文字按实际字体测量；长字段或过多换行超出空间时会阻止导出并提示，不用小字或省略号隐藏内容。
- 使用系统中文字体，Windows 通常为微软雅黑；无外部字体依赖，跨系统字形可能略有不同。
- 请保持电脑日期正确，年份与估算年龄会随日期更新。

五、隐私与验证边界
姓名、照片和完整资料仅保留在当前页面内，不上传、不持久保存。
只有序号计数保存在 localStorage；协调编号所需的 IndexedDB 不包含会员资料。
关闭或刷新页面会清除未保存资料，已下载图片请自行妥善保管。
本工具不连接会员管理后台，需要手动填写授权资料，不提供会员历史管理或同名人员识别。

本工具支持 file:// 本地打开和 HTTP/HTTPS 网页访问，测试使用 macOS Chromium。
Windows 10/11、Edge 实机未验；首次使用时请验证双击打开、年份、上传、中文排版、编号保留及下载。

assets/female-background.png、assets/backgrounds.js。
两张底图保持用户提供的原始字节；JS 内嵌相同图像供 file:// 离线导出。
工具不附带真实会员资料、照片或已用编号，首次使用由浏览器初始化计数。
