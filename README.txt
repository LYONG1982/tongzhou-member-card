同舟婚恋 · 会员卡片生成器
版本：1.5 / 2026-10-21
在线使用：https://lyong1982.github.io/tongzhou-member-card/

一、填写 → 生成卡片 → 最终预览 → 保存下载
1. 填写姓名（1–40字符，仅内部录入），选择男版晴蓝或女版柔粉。
2. 选择出生年份，填写身高、民族、婚姻状况、学历、工作、月收入、资产及三项介绍。
   卡片和最终预览均不显示真实姓名、年龄；下载文件名也不含姓名。
   初始介绍为可替换示例，请使用已授权的真实资料。
3. 点击“上传照片”，在3:4照片区拖动、缩放调整构图；方向键微调，Shift加速。
   居中保留缩放倍数；重置构图恢复初始位置和大小。取消选择不清除已有照片。
4. 点击“生成卡片”进入最终预览，此时不会下载，也不占用新编号。
5. 明确选择“卡通遮挡”或“保留原照”。卡通头像根据表单性别自动匹配。
   遮挡模式下点击照片中的脸部放置头像，拖动、调整大小或用方向键微调。
   头像下的不透明圆形为有效遮挡区域；请检查面部完整位于覆盖范围中。
   不自动识别人脸，当前支持单人单个遮挡；面部遮挡不隐藏背景或其他会员资料。
6. 点击“保存下载”，下载固定1440×1080的扁平PNG，画面与最终预览一致。
   编辑虚线和操作控件不进入PNG。下载位置由浏览器设置决定。
7. 返回修改保留表单、照片和有效遮挡参数；文字修改不移动头像。
   更换照片、改变裁切或性别后需重新放置头像。改姓名重置隐私选择及当前编号归属。
8. 制作下一位点击“重置”。关闭或刷新页面不会恢复个人资料与当前编号，只保留累计计数。

二、模板与文字
- 按指定Figma男女节点2:19、2:72的布局实施：左侧3:4照片612×816，右侧两列八项资料。
- 整卡为横向4:3，1440×1080；手机只是等比缩放预览，不改变导出布局。
- 官方Logo、口号、植物与曲线使用Figma原始背景资源；不使用旧城市背景，不提供Logo替换入口。
- 家庭情况、红娘评价、择偶要求为三个独立模块，正文24px/行高36px，分别最多2/4/3行。
- 页面建议字数按当前中文字体宽度估算，常见约50/108/81字；最终以真实排版测量为准。
  中英文、标点、Emoji和主动换行会影响容量。超出空间明确提示并阻止生成，不静默截断或缩成小字。
- 基础字段同样按实际列宽校验，过长时请精简。
- 使用本机系统中文字体，不下载外部字体；Figma的Noto Sans SC与不同系统字体有字形、换行细微差异。
- 图片与资料只在浏览器本地绘制，预览与下载共用绘制和裁切逻辑。

三、编号与兼容
- TZ-00001–TZ-09999，序号上限9999。保留原存储键tongzhou.memberCard.counter.v1及数值字段。
- 预览显示“编号待保存”，表单标题显示“待生成”。首次保存通过资源、排版和PNG检查后提交正式编号。
- 同一页面同一会员的重复保存、调整遮挡/照片/文字/性别沿用已分配号码。
- 改姓名、重置或刷新后下一次保存分配新号；不会通过姓名查找历史会员。
- 历史计数与以前保存的起始序号继续沿用；没有起始号设置入口，不重置记录，不扩大号段。
- 多窗口用Web Locks或IndexedDB排他事务协调。存储损坏、不可写或无法安全加锁时停止发号。
- 浏览器取消/阻止下载可能留下空号，已分配号码不回收；同页重试沿用该号。
- 计数仅在同一浏览器存储作用域内有效，不保证跨电脑、跨浏览器、跨用户全局唯一。
  更换环境需要维护人员核对并迁移原计数，不要清除本地存储。

四、图片支持
- JPG/JPEG、PNG、WebP、GIF首帧及浏览器可解码的BMP、AVIF等。
- HEIC/HEIF、TIFF等以浏览器解码能力为准，无法读取时请转换为PNG/JPG；不承诺支持所有格式。
- 不接受SVG/SVGZ；最大20MB、5000万像素、单边不超过20000px。
- 等比cover裁切，不拉伸。JPEG方向由浏览器读取；GIF固定实际首帧。
- 不显示照片文件名、分辨率或清晰度参数，保留简明错误提示。
- 卡通遮挡导出会合成进图片，不保留可关闭的原照片图层。

五、运行与隐私
原生HTML/CSS/JavaScript + Canvas，GitHub Pages静态托管，无服务端或外部脚本依赖。
网页源码、品牌与卡通素材公开可访问；网站访问产生常规静态请求，会员照片和资料不会上传。
姓名、照片、资料、遮挡参数仅存在当前页面内存。localStorage仅保存序号；IndexedDB仅协调编号。
下载图片由用户自行保管。本工具不连接会员后台，不提供历史资料查询或跨设备同步。
仍支持下载运行文件后直接用Chrome/Edge打开index.html；需保持assets及其他运行文件位置。
核心文件：index.html、styles.css、app.js、assets/backgrounds.js、assets/avatars.js。
资源原图：assets/figma-male-background.png、figma-female-background.png、male-avatar.png、female-avatar.png。
JS嵌入相同原图字节以支持file://离线导出；没有临时Figma URL或运行时素材下载。

建议PC Chrome/Edge使用；检查使用macOS Chromium。Windows/Edge实机未验证。
